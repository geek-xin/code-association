## 同步到 GitHub Wiki

本目录与 GitHub Wiki 内容一致。Wiki 仓库需要先在网页端创建首页才能克隆，
创建后可用以下命令同步：

```bash
git clone git@github.com:geek-xin/code-association.wiki.git /tmp/ca-wiki
cp docs/wiki/*.md /tmp/ca-wiki/
cd /tmp/ca-wiki && git add . && git commit -m "docs: sync wiki" && git push
```

> 注意：Wiki 使用裸页面名互链（如 `快速上手`），本目录用 `.md` 后缀。
> 同步脚本需要把链接后缀去掉。
