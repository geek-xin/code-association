## 一句话概括

```text
变更（git diff / 分支 / PR）
   ↓  AST 语义差异，不是文本比较
代码知识图谱（调用 / 类型 / 接口 / SQL / 配置 / 消息）
   ↓  只沿"契约"跨出本程序
其他程序里的使用点
   ↓  在对方自己的图里继续传播
影响清单 + 路径 + 风险 + 置信度
```

**关键约束：扫描范围只有其他程序。** 本程序内部的调用方、模块、测试与传播链不会进入结果。
这不是省略，而是产品定义——它要回答的是"我改了这里，别的团队要不要动"。
